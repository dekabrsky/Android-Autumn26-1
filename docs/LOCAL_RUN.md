# Локальный запуск

При установленной JDK 17 (версия, указанная в build.gradle.kts):

```sh
./gradlew test run
```

В текущем окружении установлена только JDK 21. Проверка выполнена с временным
init-скриптом, который меняет toolchain только для конкретного запуска:

```sh
cat > /tmp/kormilets-task1.gradle <<'GRADLE'
allprojects {
    afterEvaluate {
        kotlin.jvmToolchain(21)
    }
}
GRADLE
./gradlew test run -I /tmp/kormilets-task1.gradle
```

Программа читает fakePlayersDirty.csv, выводит запросы 1–8 через DSL отчёта,
отдельно выполняет потоковый поиск и сохраняет два графика варианта 2:

- build/reports/charts/top-10-teams.png
- build/reports/charts/forwards-price-goals.png

Графики создаются средствами Java2D, работают без графического окна.
Для тренда нападающие сортируются по стоимости, затем берутся окна по 5 игроков
с шагом 1. Каждая точка линии — средняя стоимость и среднее число голов окна.
Цвет точек показывает число жёлтых карточек: 0, 1–3, 4 и более.
Валюта исходных данных не задана, поэтому ось стоимости подписана в миллионах.

Team.aggregate создаёт команды со снимками состава. Равенство команд определяется
названием и городом; состав не участвует в equals/hashCode, чтобы избежать циклов
Player → Team → Player. Сумма стоимости и средние жёлтых/красных карточек используют by lazy.
Запрос 4 использует тот же агрегат.

CheaperThan означает строго меньшую стоимость. Фильтр ByPosition используется
в запросах 2 и 5. Потоковый поиск закрывает переданный Reader и останавливается
после первого совпадения.

Если в запросах 2, 3 или 4 нет подходящих объектов, выбрасывается
NoSuchElementException с пояснением. Страны без агентств не входят в результат
запроса 7. При отсутствии голов запрос 8 возвращает (0.0, 0.0).
Стоимость, равная медиане, входит в группу «не дороже медианы».
При равенстве результатов запросов 2–4 используется алфавитный порядок имён.

Тестовый отчёт: build/reports/tests/test/index.html.
Проверено 24 теста: маппинг, каждый запрос IResolver, фильтры, агрегаты,
потоковое чтение с ранней остановкой, DSL и скользящее среднее.
